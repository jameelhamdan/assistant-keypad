Choose which key does what. Keys are numbered like the keypad: 1 2 3 4 on top, 5 6 7 8 below. The encoder click always hands a request back to the PC.

Instructions you can send to Claude from the keypad: press the menu key on the status screen, or Shortcut when Claude stops.

Installing adds command hooks to ~/.claude/settings.json and registers the keypad MCP server. It leaves your other settings alone and backs up the file first. Restart open Claude Code sessions afterwards.

Pair

The keypad stores the network and a new pairing key. From then on it only accepts this computer over Wi-Fi.
